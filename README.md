# 이희재의 맛 연구소 — AI 콘텐츠 스튜디오 (프로토타입)

> 요리가 쉬워지는 30초 실험실

조리기능장 이희재 연구자의 레시피·조리 지식을 넣으면, 캐릭터 **맛조수**가 **3D 주방에서 직접 요리하는** 세로 숏폼 영상(릴스·쇼츠)과 네이버 블로그 원고를 만드는 **개인용 제작 도구**입니다.

- 3D 주방: 가스레인지·팬·냄비·선반·창문이 있는 로우폴리(블록) 스타일 연구소 주방
- 3D 음식: 레시피(요리 이름·재료)를 보고 전·달걀·나물·국·밥·면·볶음 모양과 색을 자동으로 정함. 팬 위에서 점점 익고, 전은 뒤집히고, 완성되면 접시에 담김
- 재료 소품: 재료마다 그릇·병·양념통·달걀·채소 모양으로 조리대에 차례로 나타나고 이름표가 붙음
- 완성 사진(선택): 올리면 영상에 '완성 사진'으로 나오고 3D 음식 색이 사진 색에 맞춰짐

- 대상: 나(개발자)와 어머니(검수자) 두 사람만 사용
- 비용: **0원** — 유료 API·클라우드 서버 없이 내 PC에서 실행
- 일정: 최대 4일 프로토타입 ([계획·범위](docs/PROTOTYPE_PLAN.md))

## 사용 흐름

```
① 콘텐츠 입력 → ② AI 대본 → ③ 이희재 연구자 검수 → ④ 영상 제작 → ⑤ 블로그·내보내기
```

| 단계 | 하는 일 |
| --- | --- |
| 1. 콘텐츠 입력 | 주제, 재료·분량, 조리 순서, 핵심 원리, 전문가 팁, 흔한 실수 입력 |
| 2. AI 대본 | 템플릿으로 즉시 생성(무료) 또는 무료 AI 채팅(ChatGPT·Claude·Gemini 웹)에 프롬프트를 붙여넣고 답을 다시 붙여넣기. 장면별 대사·감정·카드 편집, 버전 기록·복원 |
| 3. 연구자 검수 | 원본과 대본을 나란히 비교. 원본에 없는 분량, 재료·순서 변경, 안전 표현, "실험 결과" 같은 근거 없는 표현을 자동 표시. 체크리스트 4개를 모두 확인해야 승인 |
| 4. 영상 제작 | 3D 주방 영상 브라우저 미리보기, 완성 사진 올리기. **승인된 대본만** 1080×1920 MP4 + 커버·썸네일·레시피 카드로 렌더링 |
| 5. 블로그·내보내기 | 네이버 블로그 원고(서식째 복사), 릴스·쇼츠 게시 문구, 자막 SRT를 ZIP 한 개로 내려받기. 선택: 생성 AI(ChatGPT 이미지·Gemini 영상)용 프롬프트 팩 |

### 영상 품질 규칙 (NMXWZ 'AI Reel in 3 Prompts' 가이드 반영)

- **자막:** 1~3어절씩 튀어나오고(작게 → 조금 크게 → 보통), 말하는 단어를 강조합니다. 맛조수 대사는 흰 글자에 노란 강조, 연구자 지식(조리 노트·한 줄 팁)은 주황 글자에 흰 강조입니다. 팁·실수 문장은 더 크게 튀고 살짝 흔들리며, 굵은 글꼴에 두꺼운 테두리와 그림자를 씁니다. 캐릭터 얼굴을 가리지 않도록 턱 아래나 머리 위로 옮기고, 앱 화면이 가리는 위 220px·아래 420px은 피합니다.
- **단어 타이밍:** VoiceStudio가 켜져 있으면 받아쓰기(Whisper 계열)로 실제 어절 시간을 재서 자막을 맞춥니다. 없으면 글자 수로 추정합니다.
- **소리:** 음성 앞뒤 무음을 잘라 내고, 시작·끝에 짧은 페이드를 넣고, 팁·실수 문장 뒤에는 짧은 쉼을 둡니다. 최종 영상은 -14 LUFS(H.264 + AAC)로 맞춥니다.
- **조명·질감:** 장면마다 분위기 조명이 다릅니다(아침빛, 청록, 실수 장면은 파랑·빨강, 조리는 불빛 주황, 재료는 산뜻한 민트, 팁·엔딩은 황금빛). 테두리 조명, 비네트, 필름 질감, 각진 로우폴리(PS1 느낌) 질감을 씁니다.
- **확인:** 완성본마다 자막 한 개당 프레임 한 장(caption-check)을 저장하니, 얼굴을 가리거나 잘린 자막이 없는지 보세요.
- **생성 AI로 더 높은 품질:** 프롬프트 팩은 약 8초·대사 2줄 이하 클립으로 나뉩니다. 만든 클립을 [영상 제작]에서 같은 번호에 올리면 3D 대신 그 클립이 나오고, 검수된 목소리·자막·브랜드가 입혀집니다.

승인 후 대본이나 원본 레시피를 고치면 승인이 자동으로 풀리고 다시 검수를 받아야 합니다. "검토한"이라는 표현은 승인된 콘텐츠에만 들어갑니다.

## 빠른 시작

필요한 것: **Node.js 22.13 이상**. (선택) 음성을 넣으려면 **Python 3 + edge-tts**.

```bash
npm install
```

```bash
npm run seed
```

```bash
npm run dev
```

브라우저에서 http://localhost:5178 을 엽니다. `npm run seed`는 파일럿 샘플 3개(김치전·시금치·달걀)를 넣습니다.

### 음성: VoiceStudio (무료, 내 PC에서 실행)

1. [VoiceStudio 최신 버전](https://github.com/debpalash/VoiceStudio/releases/latest)에서 내 PC용 설치 파일을 받아 설치하고 앱을 켭니다. Windows는 `.exe`이고, 처음 켤 때 모델을 내려받느라 몇 분 걸립니다.
2. 스튜디오의 **캐릭터·목소리** 메뉴에서 연결 상태가 `VoiceStudio 연결됨`으로 바뀌면 **맛조수 목소리 자동으로 만들기 → ▶ 들어보기**를 누릅니다.
3. 마음에 안 들면 VoiceStudio 앱의 목소리 디자인에서 다듬거나 새로 만든 뒤, 스튜디오에서 그 목소리를 고릅니다.

스튜디오는 앱이 쓰는 포트(3900, 막혀 있으면 4900·5900…)를 자동으로 찾습니다. 앱을 나중에 켜도 15초 안에 알아챕니다. 모델별 이용 조건은 앱의 Model Manager에서 확인하고, 실제 사람 목소리 복제는 본인 동의가 있을 때만 씁니다.

VoiceStudio 없이 간단히 쓰려면 edge-tts도 됩니다(`pip install edge-tts` 후 스튜디오 재시작).

둘 다 없으면 자막만 있는 영상이 만들어집니다.

처음 영상을 만들 때 Remotion이 무료 렌더링용 크롬(약 100MB)을 한 번 내려받습니다. 3D 영상은 PC 성능에 따라 30초 영상 한 편에 몇 분 걸릴 수 있습니다.

### 그 밖의 명령

### 설정 (환경 변수, 모두 선택)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `5178` | 스튜디오 주소 포트 |
| `MATLAB_DATA_DIR` | `./data` | DB·음성·완성본 저장 폴더 |
| `TTS_PROVIDER` | `auto` | `auto`(VoiceStudio → edge-tts → 없음 순) · `voicestudio` · `edge` · `none` |
| `VOICESTUDIO_URL` | (자동 찾기) | VoiceStudio 주소를 직접 정할 때만 |
| `VOICESTUDIO_VOICE` / `VOICESTUDIO_MODEL` | (화면에서 고름) / `tts-1` | 목소리 강제 지정 / 엔진 (`tts-1` = 앱에서 고른 엔진) |
| `TTS_VOICE` | `ko-KR-SunHiNeural` | 캐릭터 목소리 (`edge-tts --list-voices`로 확인) |
| `TTS_RATE` / `TTS_PITCH` | `+8%` / `+15Hz` | 말 속도·높이 |
| `REMOTION_BROWSER_EXECUTABLE` | (자동 다운로드) | 이미 있는 크롬/크로미움 경로 |
| `REMOTION_GL` | `angle` | 3D 렌더링 방식. 그래픽카드가 없는 PC·서버에서 렌더링이 실패하면 `swangle` |

### 공개 전에 확인할 것

- **edge-tts**는 Microsoft의 공식 상용 API가 아닙니다. 수익 채널에는 VoiceStudio(로컬)로 바꾸는 것을 권합니다. VoiceStudio 앱은 AGPL-3.0이고, 만든 음성의 이용 조건은 엔진(모델)마다 다릅니다.
- **Remotion**은 개인·3인 이하 조직은 무료입니다. 외부 고객용 SaaS로 넓히면 유료 라이선스를 다시 검토해야 합니다.
- **무료 AI 채팅**에 넣는 레시피는 각 서비스의 데이터 정책을 따릅니다.
- 샘플 3개의 조리 정보는 **검수 전 초안**입니다. 어머니의 확인과 이름·이력 사용 동의를 받은 뒤 공개하세요.

## 구조

```
apps/studio/            관리 화면 + 로컬 서버
  server/               Express API, SQLite, TTS, 제작 작업(렌더 큐)
  web/                  React 화면 (입력·대본·검수·영상·블로그 5단계, 캐릭터 페이지)
packages/recipe-core/   데이터 모델, 템플릿 대본, AI 프롬프트·파싱, 자동 검사, 승인 규칙
packages/video/         3D 주방·맛조수·음식(three/), 2D 캐릭터(SVG), 장면 카드, 자막, Remotion 렌더러
packages/publishing/    블로그 원고, SNS 문구, SRT 자막, ZIP 묶음
docs/                   프로토타입 계획·범위
```

작업 데이터는 `data/`(DB, 음성 캐시, 완성본)에 저장되며 git에 올라가지 않습니다. 백업하려면 이 폴더를 복사하세요.
