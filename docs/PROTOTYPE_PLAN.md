# 4일 프로토타입 계획 (비용 0원 · 개인용)

원본 기획안 v1.0(2026.11.02)의 1~6주 차 범위를 **나 혼자 쓰는 비용 0원 도구**로 줄여 최대 4일 안에 동작하는 프로토타입을 만든다.

## 목표와 통과 기준

| 목표 | 통과 기준 | 상태 |
| --- | --- | --- |
| 레시피 입력 → 대본 → 검수 → 영상 → 블로그 전 과정이 한 화면에서 이어진다 | 브라우저에서 입력부터 ZIP 내려받기까지 끊김 없이 진행 | ✅ |
| 원본 재료·분량이 바뀌지 않는다 | 재료 카드·블로그 재료는 원본 데이터만 사용, 테스트로 확인 | ✅ |
| 미승인 대본은 최종 출력 불가 | 서버에서 차단(409), 승인 후 수정 시 자동 재검수, 테스트로 확인 | ✅ |
| 캐릭터 일관성 | 고정 SVG 캐릭터 1종, 기본 감정 6종, 말할 때 입 모양 | ✅ |
| 20~35초 세로 영상 3개가 실제 재생된다 | 파일럿 3개 1080×1920 MP4 (`npm run render:samples`) | ✅ (30~36초) |
| 비용 0원 | 유료 API·서버 없음 | ✅ |
| 실제 음성으로 듣고 톤 결정 | 내 PC에서 edge-tts 설치 후 확인 | ⏳ 4일 차 |
| 어머니 검수 | 샘플 3개 내용·표현 확인, 이름 사용 동의 | ⏳ 4일 차 |

## 일정

| 일 | 작업 (기획안 작업 단위) | 결과 |
| --- | --- | --- |
| 1일 차 | ① 레시피 데이터 모델 ② 대본·스토리보드 생성기(템플릿 + 무료 AI 붙여넣기) · 자동 검사 규칙 · 캐릭터 SVG 6감정 | `packages/recipe-core`, 캐릭터 시트 |
| 2일 차 | ④ 캐릭터 렌더러 ⑤ 음성·자막 ⑥ 영상 출력 엔진 | `packages/video`, 샘플 MP4 |
| 3일 차 | ③ 검수·승인 화면 ⑦ 블로그 패키징 ⑧ 작업 내역·버전·복구 | `apps/studio`, `packages/publishing` |
| 4일 차 | 내 PC 실사용 점검: edge-tts 설치·목소리 결정, 파일럿 3개 어머니 검수, 피드백 반영 | 승인된 파일럿 3개 |

1~3일 차 범위는 이 저장소에 구현되어 있다. 4일 차는 사람이 직접 확인해야 하는 일이다.

### 4일 차 체크리스트

- [ ] `pip install edge-tts` 후 서버 재시작 → 영상 단계에서 "음성 생성"으로 목소리 확인
- [ ] 목소리가 캐릭터와 맞지 않으면 `TTS_VOICE`·`TTS_PITCH`·`TTS_RATE` 조정 (`edge-tts --list-voices | grep ko-KR`)
- [ ] 어머니와 샘플 3개 검수: 재료·분량·원리·표현 확인 후 스튜디오에서 승인
- [ ] 어머니 실명·직함(조리기능장) 사용 동의 확인
- [ ] 승인된 3개를 제작해 휴대폰에서 재생 (자막 크기, 플랫폼 UI 가림 여부)
- [ ] 캐릭터 인상 피드백 정리 → 다음 단계 반영

## 원 기획안과 달라진 점

| 항목 | 기획안 | 프로토타입 | 이유 |
| --- | --- | --- | --- |
| 웹 관리자 | Next.js | Vite + React + Express | 로컬 1인용에 더 단순, Remotion과 바로 연결 |
| 대본 생성 | LLM API | 템플릿 + 무료 AI 웹 채팅 붙여넣기 | API 비용 0원 |
| 음성 | TTS API | edge-tts | 무료 (공개 전 이용 조건 확인 필요) |
| 캐릭터 | 이미지 생성 + 2D 리깅 | 코드로 그린 SVG | 무료, 매번 같은 모양 보장 |
| 정면·측면·3/4 기준 이미지 | 필수 | 정면 6감정만 | 4일 범위 밖, 다음 단계 |
| 이미지 생성(음식·배경) | 이미지 생성 API | 코드로 그린 연구소 주방 배경 | 비용 0원 |

## 다음 단계 (프로토타입 이후)

1. 캐릭터 측면·3/4 시점, 동작 추가 (손에 도구 들기 등)
2. 실제 음식 사진 업로드 → 장면에 넣기
3. 로컬 LLM(Ollama) 연결로 붙여넣기 없이 AI 대본 생성 (여전히 0원)
4. 배경음악·효과음 (저작권 무료 음원)
5. 7~10주 차 채널 운영: 콘텐츠 12~16개 게시, 포맷(코미디형·설명형) 비교

## 위험과 대응

| 위험 | 대응 |
| --- | --- |
| 잘못된 조리 정보가 어머니 이름으로 나감 | 원본 데이터 고정, 자동 검사, 체크리스트 승인 없이는 출력 불가 |
| edge-tts 서비스 변경·차단 | 자막만 영상으로 자동 전환, 공식 TTS로 교체 가능하게 분리 |

| 무료 AI 답변 형식 오류 | JSON 검증 후 오류 메시지, 재료 카드는 원본으로 강제 고정 |
