# 4일 프로토타입 계획 (비용 0원 · 개인용)

원본 기획안 v1.0(2026.11.02)의 1~6주 차 범위를 **나 혼자 쓰는 비용 0원 도구**로 줄여 최대 4일 안에 동작하는 프로토타입을 만든다.

## 목표와 통과 기준

| 목표 | 통과 기준 | 상태 |
| --- | --- | --- |
| 레시피 입력 → 대본 → 검수 → 영상 → 블로그 전 과정이 한 화면에서 이어진다 | 브라우저에서 입력부터 ZIP 내려받기까지 끊김 없이 진행 | ✅ |
| 원본 재료·분량이 바뀌지 않는다 | 재료 카드·블로그 재료는 원본 데이터만 사용, 테스트로 확인 | ✅ |
| 미승인 대본은 최종 출력 불가 | 서버에서 차단(409), 승인 후 수정 시 자동 재검수, 테스트로 확인 | ✅ |

| 비용 0원 | 유료 API·서버 없음 | ✅ |
| 실제 음성으로 듣고 톤 결정 | 내 PC에서 edge-tts 설치 후 확인 | ⏳ 4일 차 |
| 어머니 검수 | 샘플 3개 내용·표현 확인, 이름 사용 동의 | ⏳ 4일 차 |

| 3일 차 | ③ 검수·승인 화면 ⑦ 블로그 패키징 ⑧ 작업 내역·버전·복구 | `apps/studio`, `packages/publishing` |

1~3일 차 범위는 이 저장소에 구현되어 있다. 4일 차는 사람이 직접 확인해야 하는 일이다.

### 4일 차 체크리스트

- [ ] `pip install edge-tts` 후 서버 재시작 → 영상 단계에서 "음성 생성"으로 목소리 확인
- [ ] 목소리가 캐릭터와 맞지 않으면 `TTS_VOICE`·`TTS_PITCH`·`TTS_RATE` 조정 (`edge-tts --list-voices | grep ko-KR`)
- [ ] 실제 음성 길이 기준으로 대본을 다듬어 35초 안으로 맞추기 (특히 김치전 코미디형)
- [ ] 어머니와 샘플 3개 검수: 재료·분량·원리·표현 확인 후 스튜디오에서 승인
- [ ] 어머니 실명·직함(조리기능장) 사용 동의 확인
- [ ] 승인된 3개를 제작해 휴대폰에서 재생 (자막 크기, 플랫폼 UI 가림 여부)
- [ ] 캐릭터 인상 피드백 정리 → 다음 단계 반영

## 3D 주방 영상 (추가 요청 반영)

참고 영상(로우폴리 3D 주방에서 직접 조리하는 1인칭 숏폼)에 맞춰 영상을 2D 카드형에서 **3D 주방형**으로 바꿨다. 비용 0원을 지키려고 3D 모델 파일·생성형 영상 없이 Three.js 기본 도형으로 코드에서 만든다.

| 요소 | 표현 방식 |
| --- | --- |
| 주방 | 원목 바닥, 판넬 벽, 창문, 조리대·수납장, 가스레인지(불꽃), 선반 양념통, 냉장고, 발판 |
| 맛조수 | 2D 디자인을 3D로 옮김 (찐빵 몸통·조리모·고글·앞치마), 감정 6종 얼굴, 말할 때 입, 뒤집개로 젓기, 접시 들어 보이기 |
| 음식 | 레시피에서 종류 추정 → 전(팬에서 익고 뒤집힘)·달걀(냄비에서 삶고 반 갈라 담음)·나물(데쳐서 소복이)·국·밥·면·볶음 |
| 재료 | 재료마다 그릇·병·통·컵·달걀·채소 소품이 조리대에 차례로 등장, 3D 위치에 맞춘 이름표 |
| 사진 | 완성 사진을 올리면 영상 '완성 사진' 카드 + 사진 대표 색을 음식 색으로 사용 |
| 카메라 | 장면 종류별 고정 규칙: 전체 샷, 캐릭터 중간 샷, 어깨 너머 팬 샷(참고 영상 시점), 조리대 샷, 접시 클로즈업 — 장면마다 천천히 이동 |

한계: 음식은 '간단한 표현' 수준이다(실사 아님). 사진을 3D 모델로 바꾸는 기능은 없고, 사진은 색과 '완성 사진' 카드로만 쓴다. 3D 렌더링은 2D보다 오래 걸린다.

## 실제 레시피 (이희재 조리기능장 제공)

| 레시피 | 출처 | 3D 표현 | 상태 |
| --- | --- | --- | --- |
| 호두정과 | 한국노인인력개발원 강의 자료 | 팬에서 조려지는 호두 → 접시 | 재료·분량·순서는 원본 그대로, 원리·팁 문장은 초안 → 검수 필요 |
| 들깨고사리파스타 | 아산농업기술센터 강의 자료 | 냄비 속 크림 들깨 면 → 그릇 | 재료 20개를 들깨소스·파스타 재료·고명 묶음으로 입력, 원리·팁 문장 초안 → 검수 필요 |

`npm run seed`로 스튜디오에 들어간다. 원본 자료에 '원리'와 '팁'이 따로 없어서, 조리 순서에서 읽히는 내용으로 문장을 만들었다. 이 문장은 공개 전에 반드시 연구자 확인을 받는다.

## 원 기획안과 달라진 점

| 항목 | 기획안 | 프로토타입 | 이유 |
| --- | --- | --- | --- |
| 웹 관리자 | Next.js | Vite + React + Express | 로컬 1인용에 더 단순, Remotion과 바로 연결 |
| 대본 생성 | LLM API | 템플릿 + 무료 AI 웹 채팅 붙여넣기 | API 비용 0원 |
| 음성 | TTS API | edge-tts | 무료 (공개 전 이용 조건 확인 필요) |
| 캐릭터 | 이미지 생성 + 2D 리깅 | 코드로 만든 3D 캐릭터 (2D SVG 버전도 유지) | 무료, 매번 같은 모양 보장 |
| 정면·측면·3/4 기준 이미지 | 필수 | 정면 6감정만 | 4일 범위 밖, 다음 단계 |
| 이미지 생성(음식·배경) | 이미지 생성 API | 코드로 만든 3D 주방·음식 모델 | 비용 0원 |
