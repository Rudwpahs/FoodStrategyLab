# Ootto 기능 분석과 우리 스튜디오에 들일 것 (2026-11-19)

[Ootto](https://www.ootto.ai/)는 "웹사이트 주소만 주면 인스타그램 릴스를 매주 만들어 올려 주는" 유료 서비스다(셀프 $48/월부터).
공개 홈페이지 문구만 보고 기능을 정리했다. 화면 디자인·문구·코드는 베끼지 않는다(저작권). **기능만** 우리 원칙(원본 레시피 고정·연구자 승인·AI 표시)에 맞춰 우리 방식으로 만든다.

| Ootto 기능 | 내용 | 우리 스튜디오 지금 | 들일지 |

## 우리 방식으로 만드는 순서

1. **계정 진단** (`/#/audit`): 게시 기록·지표(건너뛰기율·시청 시간·저장·공유)와 게시 간격, 행동 유도 문구 여부를 규칙으로 세고, Claude가 짧은 진단문을 쓴다. "처음 만들 3개"는 아직 영상이 없는 레시피와 잘 된 연출에서 고른다. 사실은 숫자에서만, 연구자 경험은 쓰지 않는다(원칙 4).
2. **주간 계획·캘린더 + 승인 대기열** (`/#/plan`): 다음 주 게시 칸(기본 화 18:00·목 12:30·토 10:00, 지표가 쌓이면 잘 된 시간)에 콘텐츠를 배정. 휴대폰에서 카드를 밀어 승인(체크리스트 확인 후, 연구자 계정만)·수정 요청(쉬운 말 → 새 대본 버전 → 다시 렌더).
3. **자동 게시 + 댓글 답장**: 예약한 칸이 되면 승인된 최신 버전만 올린다(원칙 2). 댓글 단어 규칙 → 정해 둔 답글·DM. 둘 다 설정에서 켜야 동작하고, 실제 계정 연결은 사용자 승인 뒤(AGENTS.md).
