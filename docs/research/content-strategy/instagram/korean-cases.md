조사일: 2026-11-07
목적: 조리기능장 이희재 레시피 → 3D AI 캐릭터 '맛조수' 30초 릴스 + 인스타 게시를 위한 참고

## 0. 조사 방법과 한계 (먼저 읽기)

- 이 세션에서는 instagram.com, typecast.ai, ajunews.com 등을 직접 열 수 없었습니다(네트워크 차단). 그래서 **웹 검색 결과 요약, 기사, 나무위키, Threads 게시글 미리보기, 인플루언서 통계 사이트 미리보기**만 근거로 썼습니다.
- 팔로워 수는 **출처와 시점을 함께 적었고**, 시점을 모르면 "시점 미상"으로 표시했습니다. 확인하지 못한 항목은 "확인 못 함"으로 적었습니다.
- 각 릴스의 첫 1~3초, 커버 문구, 해시태그 개수 같은 세부 형식은 영상을 직접 볼 수 없어 **대부분 확인하지 못했습니다**. 확인된 것만 적었습니다. 정확히 알려면 사람이 휴대폰으로 각 계정을 15분 정도 직접 훑어보는 것을 권합니다(체크리스트는 맨 끝에 있음).
- Threads 게시글은 같은 계정이 인스타에 올린 글을 Threads에 그대로 올린 경우가 많아, 캡션 구조를 보는 근거로 썼습니다.

### 사례 1. 1분요리 뚝딱이형 — 캐릭터 목소리(TTS) + 1분 포맷의 대표
- 계정: Threads @1min_cook (https://www.threads.com/@1min_cook). 인스타 계정은 나무위키 링크란에 있으나 핸들·팔로워 수는 **확인 못 함**
- 규모: 유튜브 약 305만(나무위키, 시점 미상) / 2023년 기사 기준 245만. Threads 약 14.9만(프로필 미리보기)
- 형식:
  - 모든 영상이 **1분**에 맞춰져 있습니다. 촬영 후 1분에 맞게 컷 편집 → TTS를 입히는 순서로 만듭니다(타입캐스트 인터뷰 요약)
  - **목소리는 사람 목소리가 아니라 TTS**입니다. '뚝딱이형' = 타입캐스트 '용식이', 아이 목소리 '잼민이' = '하준'. 세계일보 기사도 "크리에이터 본인 목소리가 아니다"라고 보도
  - 고정 인사말 "안녕~ 1분요리 뚝딱이 형이야" + "뚝딱!" 외침(나무위키). 두 캐릭터가 주고받는 대화형 진행
- 플랫폼 운영: 2025년 3월 유튜브 채널이 삭제됐을 때 **인스타그램으로 입장문**을 냈습니다(네이트 뉴스). 인스타가 위기 때 연락 창구 역할을 한 셈
- AI 표시: AI 목소리 사용을 따로 밝혔는지는 확인 못 함
- 맛조수와의 관련: **"가상의 진행자 목소리 + 고정 인사말 + 짧은 길이"가 한국 시청자에게 거부감 없이 통한 증거**입니다

## 3. 잘 안 되는 것으로 보이는 것

1. **초기에 광고·협찬을 많이 섞기** — "광고는 계정 죽이기 딱 좋다", 3만까지 협찬 거절(사례 20).
2. **레시피를 한 단계 더 숨기기**(댓글 달아야 DM, 링크 몇 번) — 시청자 거부감·"광고인지 모르게 받으면 속는 것" 반응(사례 18). 자동 DM 오류도 있어 프로필 링크를 따로 둬야 함.
3. **조회수만 노린 남의 인기 레시피 퍼오기** — 조회수는 나와도 팔로워로 잘 안 이어지고, 원작자 표기 없는 복제는 논란(사례 20). (희본은 '따라 하기'를 숨기지 않고 비교·실패를 드러내는 방식이라 예외)
4. **주제가 흐려지는 계정** — "집밥 광고 느낌이 되면 요리 계정 느낌이 사라진다"(사례 20).
5. **유튜브식 긴 영상·셀럽 이름에만 기대는 인스타** — 백종원 인스타(약 36만, 시점 미상)는 유튜브(약 600만)에 비해 작음. 권성준도 인스타는 근황용(사례 7, 10).
6. **3:4 그리드 바깥에 둔 커버 글씨** — 2025년 1월부터 프로필 그리드가 3:4로 잘림. 커버 글씨는 가운데에 둬야 함(아래 출처).
7. **AI 표시 없는 AI 영상** — 인스타는 실질적인 AI 생성물에 'AI 정보' 라벨을 붙이고, 2026년엔 계정 단위 'AI 크리에이터/AI 생성 프로필' 라벨을 시험 중이라는 보도. "표시 안 하면 추천 노출이 제한된다"는 주장도 있으나 **공식 근거는 확인 못 함**.
8. **다른 앱 워터마크(틱톡 로고 등)가 남은 재업로드** — 노출 제한될 수 있다는 마케팅 블로그 주장(공식 확인 못 함).

## 4. 캡션 템플릿 패턴 (실제 예를 줄여서 옮김)

**A. "캡션에 레시피 전부" 형 (류수영 예)**
> 한 줄 제목(누구를 위한 요리인지) → 재료와 분량을 문장으로 이어 쓰기(밀가루 2컵, 소금 반 스푼 …) → 굽는 온도·시간으로 끝.
- 장점: 저장 가치가 높고 DM 같은 추가 단계가 없음. 맛조수에선 **원본 레시피의 재료·분량을 그대로** 넣으면 원칙 1과도 맞음.

**B. "댓글 키워드 → DM" 형 (@sosoroom.kr 예)**
> (광고) 표기 → "댓글에 '나도' 남기면 레시피를 DM으로" → "팔로우+댓글이어야 DM이 잘 감" → "프로필 링크 ○번에서도 확인" → 짧은 개인 이야기(왜 이 요리를 하게 됐는지).
- 댓글 수는 늘지만 거부감 반응도 있음. 광고면 맨 앞 표기가 관행.

**C. "고정 댓글에 레시피 + 시리즈 약속" 형 (@dimarecipe.kr 예)**
> 이모지 + "레시피는 고정 댓글에 남겨둘게요" → "쉽고 맛있는 ○○ 레시피 계속 올릴게요" → 해시태그 5개 정도(#집밥 #요리 #○○식단 #레시피 #요리스타그램).

**D. "팔로우·하트 요청" 형 (@captain_orange_kobi 예)**
> "지금까지 수백 가지 레시피, 자세한 설명과 팁" → "팔로우하고 차근차근 봐 주세요" → "하트 한 번 부탁".

(마케팅 가이드 공통 조언: 캡션 첫 줄에서 궁금하게 → 본문 → CTA는 하나만. 레시피는 "재료 / 만드는 법(번호) / 팁(💡)" 블록으로 나누면 따라 하기 쉽고 저장이 늘어난다 — https://www.contentspilot.com/ko/articles/instagram-caption-engagement-gongsik , https://github.com/hansik-receipt/Cook-Receipt-App/pull/3)

## 5. 맛조수 스튜디오에 주는 시사점 (짧게)

1. **첫 1~2초 = 완성 요리의 식감 장면**(자르기·붓기·지글거림), 그다음 맛조수 인사. 고정 인사말·엔딩 동작을 하나 정해 매번 반복(사례 1·4).
2. **30초 안에 단계 3~5개**. 단계가 많은 레시피는 '핵심 요령 하나' 편으로 나누기(사례 2·4·17).
3. **캡션에 원본 레시피 전체(재료·분량·순서)**를 넣는 것이 차별점. DM으로 숨기지 않기(사례 8·18, 원칙 1과 일치). 필요하면 같은 내용을 레시피 카드 캐러셀로도.
4. **전문성 한 줄**: "조리기능장 이희재 레시피" — 단 '검수/검증' 문구는 승인된 결과물에만(원칙 3). 숫자 하나로 기억되는 요령(예: "간장:물 1:2")을 앞에 세우면 2차 확산에 유리(사례 17).
5. **계정 주제 한 줄로 고정**(예: '조리기능장의 한식 기본기' 또는 '전통·궁중 집밥'), 초기엔 협찬 섞지 않기(사례 2·20).
6. **AI 캐릭터임을 밝히기**: 인스타 'AI 정보' 라벨 켜기 + 소개란에 "AI 캐릭터 맛조수가 진행, 레시피는 이희재 원본" 명시. 뚝딱이형 사례처럼 가상 진행자 자체는 거부감이 적음.
7. **커버는 3:4 가운데 안전 영역에 요리명 큰 글씨**.
8. **귀여운 캐릭터·음식 모양은 해외로도 퍼진다**(사례 12) — 나중에 영어 자막판 별도 계정도 고려.
