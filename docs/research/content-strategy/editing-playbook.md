# 편집 플레이북 — 화면·자막·음향·캐릭터 연출

- 작성일: 2026-11-03 · 근거: [sources.md](sources.md) (S·F 번호), [character-brand-research.md](character-brand-research.md)
- 근거 표시: **[공식]** 플랫폼 공식 · **[연구]** 학술 · **[경험]** 제작자 통념(미검증) · **[가설]** 실험할 것
- 각 항목 끝의 **[구현]** 은 현재 Remotion·Three.js 코드에 반영된 상태다.

## 0. 원칙

1. **고정 공식을 쓰지 않는다.** "N초마다 컷", "최적 길이 15초" 같은 규칙은 공식·학술 근거를 찾지 못했다 (F4, F5). 장면 길이는 **대사(음성) 길이**에 맞춰 자동으로 정해지고, 연출 유형은 권장 범위만 보여 준다.
2. **감정의 흐름을 설계한다.** 광고 연구에서 시청 유지에 영향을 준 것은 컷 수가 아니라 **놀람과 기쁨의 변화**였다 (S44, F4). 화면 전환이 많아 주의가 흩어지면 회피가 늘 수 있다 (S43).
3. **소리 없이도 이해되게, 그러나 글자로 화면을 덮지 않게** (S01, S02, S06, F6).
4. **사실처럼 보이는 AI 장면을 만들지 않는다.** 3D 주방·맛조수는 명백히 비사실적인 캐릭터 연출이고, 비교 장면에는 "설명용 연출"을 표시한다. 실제 완성 사진·실제 조리 클립은 사용자가 올린 것만 쓴다 (F10).

## 2. 자막

| 요소 | 근거 | 적용 | 상태 |
| --- | --- | --- | --- |
| 말자막 vs 정보 자막 | 자막은 이해·주의·기억을 높였다 (리뷰, S48) [연구] | 말자막: 화면 아래 1~3어절씩. 정보 자막: 위쪽 카드(재료·순서·노트) | [구현] |
| 문장 분할 | [경험] PDF 팁 | 2줄 이내, 어절 단위로 끊고 조사에서 끊지 않음 | [구현] |
| 강조 단어 | [경험] | 숫자·핵심어 강조색, 팁·실수 장면은 크게(punch) | [구현] |
| 연구자 자막 구분 | [가설] 이름과 지식이 같은 화면 (뱀파이어 효과 완화, character-brand 3.3) | 원리·팁 장면은 "연구자 자막" 스타일(다른 색) | [구현] voice `researcher` |
| 훅 장면 화면 글자 | 첫 화면 이해 + 글자 과다 감점 (S01, S06) | 질문형 훅 카드는 **말하는 문장 그대로**, 비교형은 원인 문장 카드 + 짧은 말 | [구현] |
| 소리 없는 환경 | [공식] 무음 대응 권고 (S02, S03) | 모든 대사에 자막. 단어 시간은 받아쓰기(있을 때) 또는 글자 수 추정 | [구현] |
| 과도한 효과 방지 | [공식] 텍스트 위주 릴스 덜 노출 | 카드는 화면 위쪽 1개만, 3D 화면을 가리지 않게 0.8배 축소 | [구현] |

측정값(호두정과 기준 영상, 2026-11-03): 자막이 떠 있는 동안 들린 단어가 그 자막에 있는 비율 86%, 말 시작 대비 자막 시작 -0.47~+0.02초. 글자 수 추정이라 뒤 장면에서 자막이 조금 늦다 → 받아쓰기 모델 설치 시 개선 (AUDIT.md 3절).
