**한계:** instagram.com과 Meta 개발자 문서는 이 환경에서 직접 열 수 없어 검색 요약·기사·분석 글로 확인했다. 팔로워 수는 출처·시점을 같이 적었고, 확인 못 한 것은 원문에 "확인 못 함"으로 남겼다. 숫자(해시태그 5개, 하루 게시 한도 등)는 실제 계정에서 다시 확인할 것.

## 세 조사에서 겹친 결론

1. **레시피를 글로 따로 준다.** 영상만으로는 분량을 알기 어렵다. 류수영·한식사랑은 캡션에 전부, 다른 계정은 고정 댓글·DM·카드로 준다. 우리는 원본 그대로 싣는 것이 차별점이다(원칙 1과도 맞음).
2. **"댓글 달면 DM으로 레시피"는 거부감이 있다.** 한국 반응("속는 것 같다")과 Eater 보도("사기 같다") 모두. → 우리는 숨기지 않고 본문에 싣는다.
3. **역할을 매번 밝힌다.** 귀여운 진행자 + 진짜 전문가 (Cooking with Dog, 1분요리 뚝딱이형의 TTS 진행). AI 인물은 바이오에만 작게 적었다가 들키면 역풍(Mia Zelu). 맛조수가 먹어 본 척하지 않는다(Lil Miquela 비판).
4. **추천 신호는 시청 시간, 도달 대비 좋아요·보내기(공유)·저장.** 비팔로워에게는 보내기가 더 중요하다.
5. **고정 인사·엔딩·시리즈 이름**이 계정을 기억하게 한다 (밥솥갸루 엔딩 포즈, 뚝딱이형 인사).
6. **첫 장면에 완성 요리**(반갈샷·지글거림)와 "왜?" 질문.
7. **프로필 격자는 3:4로 잘린다.** 표지 글씨는 가운데 1080×1440 안에.
8. **해시태그는 5개 이하**(2025-12 공지 보도. API 문서는 아직 30개), 검색어는 본문에.
9. **체험용 릴스**(비팔로워에게 먼저)로 첫 장면을 시험할 수 있다 (API `trial_params`).
10. **건강·효능 문구**(다이어트, 혈당 등)는 추천에서 빠질 수 있다.

## 아직 넣지 않은 것 (다음 후보)

- **댓글로 다음 편 정하기·캐릭터 말투 답글**(Duolingo식): 댓글 읽기 권한(instagram_business_manage_comments)과 검수 흐름이 필요.
- **첫 장면 완성 요리 우선**: 결과 선공개형·감각형 훅의 순위를 올릴지, 실제 게시 성과(인사이트)로 정하기.
- **프로필 소개란·AI 프로필 라벨**: 앱에서 직접 켜야 함 (API 없음). 소개란 예: "조리기능장 이희재의 레시피를 AI 캐릭터 맛조수가 설명해요."
- **하루 게시 한도 확인**(`content_publishing_limit`): 하루에 여러 개 올릴 때만 필요.
