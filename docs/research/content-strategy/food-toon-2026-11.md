# 3D 음식을 '확실한 만화풍'으로: 조사·결정·결과 (2026-11-21)

사용자 지적: "3D 음식이 실제 요리처럼 보이지 않고 자연스럽지 않다." 앞선 조사(`food-realism-2026-11.md`)에서 '조금 어색한 사실풍'이 가장 거부감이 크고, 확실한 만화풍이나 진짜는 괜찮다는 연구를 찾았다. 사용자는 실제 음식을 찍을 수 없어 **3D 음식을 반쯤 사실적인 것이 아니라 확실한 만화풍으로** 가기로 정했다. 이 문서는 그 방향을 어떻게 구현할지에 대한 조사(약 30분)와 결정, 결과다.

출처 표시: **[연구]** 동료 심사 논문, **[공식]** 제작사·도구 공식 문서, **[실무]** 업계 가이드·튜토리얼·인터뷰(근거 약함), **[관찰]** 이 저장소의 실제 프레임. 이번 조사 환경에서는 웹 페이지 본문을 직접 열 수 없는 곳이 많아(80.lv, medium.com, news-medical.net 등) **검색 결과 요약으로만 확인한 출처는 (요약만)** 이라고 적었다.

### 근거가 갈리거나 없는 것
- **선명한 색**: 애니·일러스트 실무는 "실제보다 채도 높게"(T5·T7), 연구는 채도↑ → 신선·맛 기대↑이지만 **너무 높으면 인공적**(이전 조사 E3, Liu 외 2022). → 채도를 조금만(+18%) 올린다.
- **외곽선을 넣을지**: 애니 음식(특히 사실적인 쪽, 예: 식극의 소마)은 선을 빼고 그라데이션을 쓰기도 하고(CLIP STUDIO 비교), 캐주얼 게임은 굵은 선을 쓰기도 한다. 효과를 잰 연구는 찾지 못했다. → 우리 맛조수는 선이 없는 매끈한 장난감 같은 입체라, **검정 굵은 선 대신 음식 색의 짙은 톤으로 가는 선**을 택했다(선택지: 선 없음 / 짙은 톤 가는 선 / 검정 굵은 선).
- **칼같은 셀 음영 vs 부드러운 장난감 음영**: 둘 다 '확실한 만화풍'(T1)이다. 맛조수와 한 세계로 보이려면(T12) 칼같은 2단보다 **경계가 아주 조금 부드러운 3단**이 맞다고 판단(주관 판단, 연구 없음).
- **번쩍임(별 모양 반짝이) 효과**: 요리 게임·애니에 흔하지만 근거를 찾지 못했고 과하면 유치해 보여 넣지 않음.

### 김은 뜨거운 음식에만 (레시피 충실)
예전에는 완성 접시마다 김을 올려, 찬물에 헹군 시금치나물·얼음물에 식힌 반숙 달걀·식혀 먹는 호두정과에도 김이 났다. 원본 조리와 다른 장면이다. recipe-core `servedHot`이 정한다:
- 요리 이름이 찬 요리(나물·무침·정과·강정·샐러드·냉면 등)면 김 없음
- **마지막 두 단계**에 식히는 말(얼음물·찬물·식혀·냉장 등)이 있으면 김 없음. '식힘망'은 눅눅해지지 않게 올려 두는 것이라 뜨거운 음식으로 본다. 중간 준비 단계(파스타 소스 '식혀서 냉동보관')는 보지 않는다
- 그 밖에는 종류로: 나물은 차게, 나머지는 뜨겁게
- 결과: 김치전·들깨고사리파스타 = 김 있음 / 시금치나물·반숙 달걀·호두정과 = 없음. 조리 중(불 위)에는 모두 김.

### 지킨 것
- 음식 색·조각은 여전히 recipe-core `foodProfile`이 원본 재료로 정한다. 원본에 없는 고명을 새로 그리지 않았다(깨는 원본에 깨가 있을 때만).
- 캔버스(WebGL)는 하나 그대로. 화면 전체 후처리 없음.
- 맛조수(`Chef3D.tsx`)·무대(`Sets.tsx`)는 바꾸지 않았다.

- 맛조수는 선이 없는 매끈한 입체라, 음식(외곽선 있음)과 나란히 나오면 아주 조금 다른 그림처럼 보일 수 있다. 맛조수에도 같은 외곽선을 넣을지는 **사용자 결정**(이번에는 맛조수·무대는 바꾸지 않았다).
- 3D로 '진짜 같은 맛'은 여전히 한계다. 진짜 질감이 필요하면 연구자 촬영 영상(실제 촬영 모드)이 답이다(`food-realism-2026-11.md`).

## 5. 2차 수정: 실제 영상에서 드러난 문제 (2026-11-21 저녁)

1차 만화풍(커밋 3e698a7) 뒤 클라우드에서 실제로 만든 영상 4편(호두정과·김치전·시금치나물·들깨고사리파스타)을 사용자가 보고 "음식이 이상하고 실제 요리 같지 않다"고 했다. 작은 비교 그림에서는 괜찮아 보였지만 실제 영상 프레임에서는 아래 문제가 보였다. 이번에는 **실제 영상과 같은 대본(그 4편의 이야기 대본)으로 같은 장면 종류(첫 화면·재료·조리·완성 접시·엔딩)를 그려 보는 도구**(`tools/content-lab/storyframes.ts`)를 먼저 만들고, 휴대폰 크기(540px 폭)로 보며 고치고 다시 그리기를 여덟 번 했다(마지막 두 번은 김치전: 김치가 깍둑 썬 토마토·페퍼로니처럼, 다 익은 전이 갈색 원판처럼 보인다는 검토 의견).

### 렌더 시간
측정: `tools/content-lab/rendertime.ts`(샘플 대본의 정해진 60프레임을 실제 영상으로, 준비 렌더 1번 버리고 2번째를 잼), 소프트웨어 WebGL(`REMOTION_GL=swangle`, 배포 서버와 같은 방식), CPU 4개. 같은 머신에서 다른 작업 없이(부하는 렌더 자신 약 4) **새 코드를 먼저, 이어서 예전 코드(1차 만화풍 3e698a7의 packages를 작업 폴더에 잠시 꺼내서)** 한 번씩 쟀다. 구간은 1차 때와 같다.

| 구간 | 예전 (1차 만화풍) | 이번 | 변화 |
| --- | --- | --- | --- |
| 김치전 562~621 (팬에서 부치는 조리) | 83.0초 | 77.2초 | 약 −7% |
| 호두정과 577~636 (완성 접시·엔딩) | 89.1초 | 81.9초 | 약 −8% |
| 들깨고사리파스타 337~396 (냄비 속 면) | 97.1초 | 94.7초 | 약 −2% |

- 한 번씩만 재서 5% 안팎은 오차일 수 있다. 결론은 **같거나 조금 빠르다**(면 가닥·전·잎의 꼭짓점과 외곽선 그리기는 늘었지만, 불꽃 점광원이 빠지고 음식 재질에서 ACES 계산이 빠졌다).
- 측정 뒤에 김치 조각 모양(물결치는 잎·줄기 띠)·파스타 고명 채·젖은 윤기·냄비 면 굵기를 고쳤다. 조각 수와 그리기 횟수는 거의 같다(고명 채 3번 추가). 최종 코드로 김치전 구간을 다시 재니 76.6초(측정 때 77.2초와 같은 수준).
- 정지 화면(`storyframes.ts`, 브라우저 하나로 28장, 첫 장 빼고 평균): 프레임당 약 4.0초 (고치기 전 같은 도구 약 5.2초는 측정 때 부하가 달라 참고용으로만).

### 아직 어색한 것 (직접 본 것)
전후 비교 그림(같은 대본·같은 프레임, 요리별 한 줄 + 반숙 달걀 샘플 한 줄): 작업 보고에 첨부(`before.jpg`·`after.jpg`·`compare.jpg`), `storyframes.ts`·`foodframes.ts`로 그렸다.

| 요리 | 좋아진 것 | 아직 어색한 것 |
| --- | --- | --- |
| 바삭한 김치전 | 팬 가운데 전구 같은 빛이 사라짐. 주황빛 반죽 + 들쭉날쭉한 바삭한 가장자리 + 납작한 빨간 김치 잎·연한 줄기로 '김치전'으로 읽힌다(갈색 원판·피자·오믈렛이 아님). 실패 전은 연하고 번들거리는 같은 전 | 김치 잎에 배추 잎맥 같은 결이 없어 '빨간 조각'에 가깝다. 노릇한 얼룩은 옅어서 잘 안 보이고, 바삭한 띠는 가까운 화면에서만 또렷하다. 반죽을 막 부은 단계(조리 앞)는 연한 살구색이라 맛있어 보이지는 않는다 |
| 호두정과 | 주황 젤리 → 골·주름이 있는 호두 반쪽, 데친 호두는 연한 황갈색, 조린 호두는 호박색 갈색 + 윤기 점. 팬(위에서)에서 호두로 잘 읽힌다 | 접시를 낮은 각도·작은 크기로 보면 여전히 갈색 덩어리로 뭉쳐 보일 때가 있다. 시럽이 흐르는 '줄기' 윤기는 없고 점뿐 |
| 시금치나물 | 서 있는 풀 → 짙은 초록 잎을 눕혀 소복이 + 연두 줄기 + 마늘 알갱이 + 참기름 윤기. 끓는 물에는 밝은 초록 잎이 뜨고, 실패작은 누런 올리브색 | 잎이 실제 데친 시금치보다 크고 또렷해 '생잎 더미'처럼 보일 수 있다. 분홍 뿌리 끝은 작은 막대처럼 보인다 |
| 들깨고사리파스타 | 지문 무늬 → 봉긋한 면 더미(엇갈린 고리·들린 가닥·깊이 그늘), 밀색 면과 회갈색 소스가 구별되고 고사리 줄기(말린 순 머리)가 보인다. 접시에는 원본의 참나물채가 초록 채로 | 냄비를 바로 위에서 크게 찍으면 가닥이 굵어 칼국수처럼 보인다. 접시 둥지는 감은 줄이 많아 조금 밧줄 뭉치 같다. 양파채·버섯은 작게 줄였지만 무엇인지 알아보기는 어렵다 |
| 반숙 달걀(샘플) | 냄비 물이 덜 탁한 하늘색, 접시는 거의 그대로(노른자가 조금 더 선명) | 냄비 속 껍질째 달걀은 여전히 밋밋한 동그라미 |

- 공통: 재료 소품의 외곽선은 멀리서 2~3화소로 가늘다. 맛조수는 외곽선 없는 매끈한 입체라 외곽선이 있는 음식·그릇과 그림체가 조금 다르다(맛조수는 이번에도 바꾸지 않음, 사용자 결정 사항).
- 3D 만화 음식으로 '진짜 맛있어 보임'에는 한계가 있다. 실제 질감이 필요하면 연구자 촬영 영상(실제 촬영 모드)이 답이다(`food-realism-2026-11.md`).
