# Modal 클라우드에 스튜디오 올리기 (컴퓨터 없이 휴대폰으로)

서버를 직접 만들거나 명령창을 쓸 필요가 없습니다. **가입 → 열쇠 3개 넣기 → 버튼 한 번**이면 됩니다(휴대폰 브라우저로도 가능).

- 스튜디오 주소: **https://rudwpahs--matlab-studio-web.us-east.modal.run** (안드로이드 앱에 들어 있는 주소와 같음. 배포가 끝나면 Actions 요약에도 나옵니다)
- 비용: Modal 무료 플랜(Starter)은 **매달 $30 무료 크레딧**을 줍니다. 아래 2단계에서 **지출 한도를 $0**으로 정하면, 크레딧을 다 써도 돈이 청구되지 않고 작업이 멈춥니다.
- 영상 1편 예상 비용 (**추정, 아직 실측 전**. 실제 값은 Modal → Usage & Billing에서 확인):
  - 후보 영상 미리보기: **0원** (휴대폰 브라우저가 그림)
  - 후보 목소리 넣기 (버튼을 눌렀을 때만): 후보 5개 × 대사 약 8줄을 GPU(L4)로 → **약 $0.2~0.5**
  - 고른 영상 완성(MP4): 목소리 + 렌더(CPU 최대 8개) 10~30분 → **약 $0.3~0.6**
  - 합계 **한 편 약 $0.5~1** → 무료 크레딧 $30이면 한 달 30편 안팎
  - 계산 근거: L4 GPU 시간당 약 $0.8, 목소리 GPU는 **최대 3대까지 동시에** 켜지고 마지막 요청 4분 뒤 꺼짐(켜져 있는 4분도 요금), CPU 1개 시간당 약 $0.05 (2026-11 [Modal 가격](https://modal.com/pricing) 기준)
- 주소는 인터넷에 열려 있고, 로그인(비밀번호 10자 이상, 10번 틀리면 15분 잠김)으로 보호됩니다.
- 확인한 근거 (2026-11-04): [Modal 가격](https://modal.com/pricing), [결제 안내](https://modal.com/docs/guide/billing), [지출 한도](https://modal.com/docs/guide/budgets)

## 1. Modal 가입

1. https://modal.com → **Sign up** → **GitHub로 가입**(가장 간단)
2. 결제 수단(카드)을 등록합니다. Modal은 무료 플랜도 카드 등록이 필수입니다(본인 확인용). 다음 단계에서 지출 한도를 $0으로 막습니다.

## 2. 지출 한도 $0 (꼭 하세요)

Modal → **Settings → Usage & Billing** → **Spend limit**을 `0`으로 저장.
→ 무료 크레딧을 넘는 작업은 Modal이 멈춥니다. 청구되지 않습니다.

## 3. 열쇠 3개를 GitHub에 넣기

1. Modal → **Settings → API Tokens → New Token** → 화면에 나온 두 값을 복사
   - `Token ID` (ak-로 시작)
   - `Token Secret` (as-로 시작)
2. GitHub 저장소 `Rudwpahs/FoodStrategyLab` → **Settings → Secrets and variables → Actions → New repository secret**에서 하나씩 추가:

| 이름 | 값 |
| --- | --- |
| `MODAL_TOKEN_ID` | Token ID |
| `MODAL_TOKEN_SECRET` | Token Secret |
| `STUDIO_SETUP_CODE` | 직접 정하는 **설정 코드**. 최소 8자, 남이 짐작하기 어렵게 **12자 이상**(문장·숫자 섞기)을 권합니다. 처음 계정을 만들 때 한 번만 씁니다 |

이 값들은 채팅·메모에 붙여넣지 말고 위 화면에만 넣으세요.

## 4. 배포 버튼 누르기

GitHub 저장소 → **Actions → Deploy to Modal → Run workflow** → 브랜치 `main` → **Run workflow**

- 먼저 테스트·타입 검사가 돌고, **통과해야만** 배포합니다. 테스트가 깨지면 서버는 그대로 둡니다.
- 처음에는 **20~40분** 걸립니다(서버 이미지 만들기). 다음부터는 몇 분.
- 끝나면 실행 화면 맨 아래 **Summary**에 **스튜디오 주소**가 나옵니다.
- 그 뒤로는 `main`에 새 기능이 들어갈 때마다 자동으로 다시 배포됩니다. **직접 넣은 설정(아래 '설정 바꾸기')은 배포해도 지워지지 않습니다.**
- 서버 오류 기록은 공개 저장소의 Actions 화면에 찍지 않습니다. Modal → **Apps → matlab-studio → web**(또는 Voice) → **Logs**에서 보세요.

## 5. 휴대폰에서 첫 계정 만들기

1. 스튜디오 주소를 엽니다.
   - **아이폰**: **사파리**로 엽니다.
   - **안드로이드**: 크롬으로 열거나, 맛 연구소 앱(APK)을 설치하면 주소를 넣지 않아도 바로 열립니다.
2. **설정 코드**(3단계에서 정한 값), 이름, 아이디, 비밀번호(10자 이상)를 넣고 **계정 만들고 시작하기**.
3. 다음부터는 아이디·비밀번호로 로그인합니다.

**앱처럼 쓰기 (홈 화면에 추가)**

- **아이폰(사파리)**: 아래쪽 **공유 버튼(□↑)** → **홈 화면에 추가** → **추가**. 홈 화면에 생긴 맛 연구소 아이콘으로 열면 주소창 없이 앱처럼 열립니다. (아이폰에는 APK를 설치할 수 없습니다.)
- **안드로이드(크롬)**: 오른쪽 위 **⋮** → **홈 화면에 추가**. 또는 APK 설치.
- 아이폰에서 사진을 올릴 때 **사진 찍기 · 사진 보관함 · 파일**을 고를 수 있고, HEIC 사진은 자동으로 JPG로 바뀝니다.

**계정 추가 · 비밀번호를 잊었을 때**

- **계정 추가**: 로그인한 뒤 위쪽 **계정** → **도와주는 사람 계정 추가**. 연구자 계정이 정해져 있으면 연구자 계정만 추가할 수 있어요.
- **내 비밀번호 바꾸기**: **계정** → **비밀번호 바꾸기** (다른 기기의 로그인은 끊겨요).
- **비밀번호를 잊었을 때**: 로그인 화면의 **비밀번호를 잊었어요** → 설정 코드(3단계에서 정한 값)와 새 비밀번호. 그 계정의 로그인은 모두 끊겨요.
- **연구자 계정**: 첫 계정을 만들 때 "연구자 본인 계정이에요"를 체크하면 그 계정만 승인할 수 있어요. 예전에 만든 계정이라면 연구자 본인이 로그인해 **계정** → **이 계정을 연구자 계정으로 정하기**를 한 번 누르세요(한 번 정하면 화면에서는 바꿀 수 없어요).
- 비밀번호를 10번 틀리면 15분 동안 잠깁니다. 15분 뒤 다시 해 보세요.

## 6. 처음 한 번: 맛조수 목소리 준비

배포 뒤 서버가 처음 켜지면 **자동으로** GPU에서 목소리 엔진을 내려받고 '맛조수' 목소리를 만듭니다(10~30분 예상). 그동안에도 스튜디오는 쓸 수 있고, 영상 만들기만 목소리 준비 뒤에 하세요.

**다른 목소리·말 빠르기**: [맛조수·목소리] 화면(휴대폰은 아래 [맛조수] 탭)에서 맛조수 기본 목소리 말고 다른 목소리(톤을 낮춘 맛조수, 차분한 여성, 남성 등)와 말 빠르기(느리게~빠르게)를 고를 수 있습니다. '모든 목소리로 만들기'를 누르면 같은 문장을 목소리마다 들어 볼 수 있어요(GPU 사용). 목소리마다 저장소에 기준 녹음(`tools/setup/voices.json`, `tools/setup/voices/`)이 있어 어디서 만들어도 같은 목소리가 납니다. 클라우드에서는 목소리 엔진이 '쓸 때만 켜져요'로 표시됩니다.

## 7. 레시피 사진·파일로 만들기 켜기 (Claude API)

[새로 만들기]에서 레시피 사진·PDF를 올리면 Claude가 글자를 읽어 레시피로 옮기고, 주제 후보를 보여 줍니다. 주제를 고르면 후보 영상 5개가 나옵니다.

1. https://console.anthropic.com → 가입 → **Billing**에서 소액 충전(예: $5) → **API Keys → Create Key**
2. GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret
   | 이름 | 값 |
   | --- | --- |
   | `ANTHROPIC_API_KEY` | 만든 열쇠 (sk-ant-…) |
3. Actions → **Deploy to Modal → Run workflow**
4. (선택) 한 달 한도·모델·생각 정도는 아래 **'설정 바꾸기'**에서 정합니다. 기본 한도는 $100.

- 기본 모델은 손글씨를 잘 읽는 상위 모델이고 생각 정도는 `high`(손글씨 대조에 유리)입니다. 레시피 사진 한 장 **약 $0.1~0.2(약 140~280원, 추정)**. 기본 한도 $100이면 한 달 수백 장. 한도에 닿으면 그달은 "직접 입력"만 됩니다. 더 아끼려면 '설정 바꾸기'에서 `CLAUDE_MODEL`에 더 싼 모델 ID(Anthropic 가격표 참고)를 넣습니다.
- 재료·분량·순서는 적힌 그대로 옮기고, 흐린 글자는 추측하지 않고 "확인할 곳"으로 알려 줍니다. 자료에 없던 주제·핵심 원리·흔한 실수는 **"AI 제안 · 확인 필요"**로 표시됩니다. 주제 후보는 처음에 3개가 나오고(‘다른 주제 더 보기’로 5개씩 더, 1회 약 $0.03), 각각 레시피의 몇 번 순서·팁에서 나왔는지 인용이 붙습니다. 인용이 원문에 없거나 레시피에 없는 숫자·건강 주장이 들어 있으면 서버가 뒤로 미루고 "확인 필요"로 알려 줍니다. 승인 전에 꼭 확인하세요.
- **AI 티 다듬기 (im-not-ai)**: [검수·승인]·[주제·영상 고르기]의 대사와 [게시·기록]의 블로그 원고에 버튼이 있습니다. 규칙 검사(무료)로 AI 티를 찾은 뒤, Claude가 im-not-ai 룰북(85개 패턴)대로 다듬고, 서버가 숫자·분량·인용·말투·변경률을 다시 검사해 걸린 문장은 원래대로 둡니다. 전후를 보고 [적용]을 눌러야 반영됩니다(대사는 새 대본 버전 → 재검수). 연구자 답변과 재료·순서·팁 목록은 보내지 않습니다. 1회 약 $0.1, 레시피 읽기와 같은 월 한도를 씁니다. 규칙 검사에서 AI 티가 없으면 Claude를 부르지 않습니다.
- **영상 자동 품질 검사**: 영상을 만들 때마다 ① 장면별 음성을 받아써서 대사와 맞춰 보고(중간에 끊겨 만들어진 음성은 한 번 다시 만듦), ② 완성 영상의 소리로 대사 끝 잘림·목소리 없는 장면·3초 넘는 무음을, ③ 화면으로 검은 화면을 검사합니다. 대사 잘림이 있으면 그 장면을 음성 끝까지 늘려 자동으로 한 번 다시 만듭니다. 결과는 [영상·블로그]와 [검수·승인] 화면에 나오고, 오류가 남아 있으면 승인할 때 한 번 더 확인합니다.
- **인스타그램 올리기** (설정: `docs/INSTAGRAM_SETUP.md`, 사례 조사: `docs/research/content-strategy/instagram-cases.md`): 설명 글에 재료·만드는 법을 원본 그대로 싣고 해시태그는 5개까지. 표지(3:4 격자 안에 제목)를 함께 보내고 AI 정보 라벨을 요청합니다(받지 않는 계정이면 앱에서 켜라고 알려 줌, 끄기: '설정 바꾸기'의 `IG_AI_LABEL=0`). [체험용 릴스로 올리기]를 켜면 팔로워가 아닌 사람에게 먼저 보여 줍니다. [레시피 카드 N장 올리기]는 넘겨 보는 카드 게시물을 따로 올립니다. 올리기 전 점검 목록이 화면에 나옵니다.
- 올린 원본 사진·파일은 콘텐츠와 함께 보관되어 언제든 대조할 수 있습니다.
- 후보 영상 5개는 브라우저가 미리보기로 그리고(렌더 비용 0원), **[목소리 넣기]를 눌렀을 때만** GPU로 맛조수 목소리를 넣습니다. **고른 1개만** 서버에서 완성 영상(MP4)으로 만듭니다.

## 설정 바꾸기 — 어떤 값이 어디에 있나

비밀값은 두 곳에 나뉘어 있습니다.

**① GitHub 비밀값** (저장소 → Settings → Secrets and variables → Actions). 배포할 때마다 Modal 비밀값 `matlab-studio`에 다시 써 넣습니다. **Modal 화면에서 `matlab-studio`를 고치면 다음 배포 때 지워지니**, 이 값들은 GitHub에서 바꾸세요.

| 이름 | 뜻 |
| --- | --- |
| `MODAL_TOKEN_ID`, `MODAL_TOKEN_SECRET` | 배포용 Modal 열쇠 |
| `STUDIO_SETUP_CODE` | 첫 계정 만들 때 쓰는 설정 코드 |
| `ANTHROPIC_API_KEY` | 레시피 읽기·AI 티 다듬기용 Claude API 열쇠 |
| `INSTAGRAM_APP_ID`, `INSTAGRAM_APP_SECRET` | 인스타그램 자동 게시용 Meta 앱 정보 (`docs/INSTAGRAM_SETUP.md`) |

**② Modal 비밀값 `matlab-settings`** — 직접 고치는 설정. 첫 배포 때 빈 묶음으로 한 번 만들어지고, **배포가 절대 덮어쓰지 않습니다.**

바꾸는 법: Modal → **Secrets** → **matlab-settings** → **Edit** → 이름·값 추가 → **Save**. 서버가 다음에 켜질 때(20분 쉬어서 잠든 뒤 다시 열 때, 또는 다음 배포 뒤) 적용됩니다.

| 이름 | 기본값 | 뜻 |
| --- | --- | --- |
| `CLAUDE_MONTHLY_BUDGET_USD` | `100` | Claude API 한 달 사용 한도(달러). 닿으면 그달은 직접 입력만 |
| `CLAUDE_MODEL` | 서버 기본(상위 모델) | 레시피 읽기·다듬기에 쓸 모델 ID. 싼 모델로 바꾸면 비용이 크게 줄어요 |
| `CLAUDE_EFFORT` | `high` | 생각 정도: `low`·`medium`·`high`·`xhigh`·`max` |
| `IG_AI_LABEL` | (켜짐) | `0`이면 인스타그램 AI 정보 라벨 요청을 끔 |
| `PUBLIC_URL` | 자동 | 스튜디오 공개 주소. 자동으로 못 알아낼 때만 넣기 |
| `VOICE_PARALLEL` | `3` | 후보 목소리를 동시에 만들 GPU 수(1~3). 줄이면 느려지지만 총비용은 거의 같아요 |

예전에 GitHub 비밀값으로 `CLAUDE_MONTHLY_BUDGET_USD`·`CLAUDE_MODEL`을 넣어 두었다면 그 값도 계속 쓰지만, `matlab-settings`에 같은 이름이 있으면 **`matlab-settings`가 이깁니다.**

## 알아 둘 점

- **잠들기**: 20분 동안 아무도 쓰지 않으면 서버가 잠들어 돈이 들지 않습니다. 다음에 주소를 열면 **10~30초** 뒤 깨어납니다. 깨어나는 동안 버튼을 누르면 "서버가 잠에서 깨는 중이에요" 안내가 나올 수 있어요. 잠시 뒤 다시 누르세요.
- **영상 만들기 중 앱 닫기**: 괜찮습니다. 제작 중에는 서버가 스스로 깨어 있습니다. 다시 열면 진행 상황을 이어서 보여 주고, 연결이 잠깐 끊겨도 "연결 확인 중"으로 자동으로 다시 확인합니다. 만드는 중에는 같은 콘텐츠로 또 만들기를 누를 수 없습니다(비용이 두 번 나가지 않게).
- **목소리 GPU**: 목소리를 만들 때만 켜지고(최대 3대 동시), 마지막 요청 4분 뒤 꺼집니다. 처음 켜질 때 1~3분 더 걸릴 수 있습니다.
- **데이터**: 레시피·영상·승인 기록은 Modal 저장소(Volume `matlab-data`)에 남습니다. 서버가 잠들거나 다시 배포해도 지워지지 않습니다. 중요한 영상·원고는 휴대폰에도 내려받아 두세요.
- **드물게 중단**: Modal은 아주 드물게 서버를 옮기며 작업을 끊을 수 있습니다(선점). 그러면 진행 중이던 영상은 "실패"로 표시되니 다시 누르면 됩니다.
- **사용량 확인**: Modal → Usage & Billing에서 이번 달 쓴 금액을 볼 수 있습니다.

## 문제가 생기면

| 증상 | 확인할 곳 |
| --- | --- |
| Actions가 노란 경고로 끝남 | 3단계 비밀값 이름·값 확인 |
| Actions의 test 단계 실패 | 테스트가 깨진 코드라 배포하지 않은 것. 개발자에게 알려 주기 |
| Actions 배포 단계 실패 | 실행 로그의 빨간 줄을 개발자에게 보여 주기 |
| "스튜디오가 응답하지 않아요" | Modal → Apps → matlab-studio → web → Logs |
| 주소를 열면 오래 걸림 | 잠에서 깨는 중(최대 30초). 처음 배포 직후에는 몇 분 |
| 영상에 목소리 오류 | Modal → Apps → matlab-studio → Voice → Logs. 목소리 준비(6단계)가 끝났는지 확인 |
| 설정을 바꿨는데 그대로 | 서버가 다시 켜져야 적용. 20분 쉬었다 열거나 다시 배포 |
| "지출 한도" 때문에 멈춤 | 이번 달 무료 크레딧을 다 쓴 것. 다음 달에 다시 되거나, 한도를 올리면 유료로 계속 |

## 개발자용 메모

- 구성: `deploy/modal/app.py` (web 함수: Node 스튜디오 전체, CPU 0.125~8코어·메모리 1~16GB 탄력, 요청 없으면 20분 뒤 잠듦 / Voice 클래스: VoiceStudio+VoxCPM2 on L4 GPU, 최대 3대, 4분 뒤 꺼짐)
- 비밀값: `secrets=[matlab-studio, matlab-settings]` — 뒤의 `matlab-settings`가 같은 이름을 덮는다. 워크플로는 `matlab-settings`를 `--force` 없이 만들어 이미 있으면 건드리지 않는다.
- 배포 워크플로: `test` 작업(typecheck·tools 타입 검사·vitest)이 통과해야 `deploy` 작업이 돈다. 배포 뒤 `/api/health`와 `/api/auth/me`가 200인지 확인한다. stderr 로그는 Actions에 찍지 않는다(`modal-logs.yml`도 시스템 기록만).
- 목소리 중계: `deploy/modal/voice_proxy.py` — 웹 컨테이너 안 `127.0.0.1:3901`이 VoiceStudio처럼 보이고, 요청을 GPU 함수 호출로 넘긴다. `/health`(버전 `modal`)·엔진/목소리 목록은 GPU를 깨우지 않게 바로 답하거나 기억해 둔 값을 쓴다. 화면은 버전 `modal`을 보고 '쓸 때만 켜져요'로 표시한다.
- DB: 컨테이너 디스크(`/root/matlab-db/studio.db`)에서 쓰고 5초마다 `/data/studio.db`로 복사(`apps/studio/server/dbSnapshot.ts`). 새 컨테이너는 복사본에서 시작. 그래서 볼륨의 `studio.db`를 밖에서 고치면 다음 복사 때 덮어써진다(계정 추가·비밀번호 재설정은 서버 안에서 한다: `POST /api/auth/users`, `/api/auth/password`, `/api/auth/reset`).
- 제작 중 깨워 두기: `KEEPALIVE=1`이면 제작하는 동안 1분마다 공개 주소의 `/api/health`를 부른다.
- 첫 계정: `STUDIO_SETUP_CODE`(8자 이상)가 있고 계정이 없으면 화면에서 만들기(`POST /api/auth/setup`), 틀리면 로그인 실패처럼 횟수 제한.
- 로컬 검증(2026-11-04): 실제 VoiceStudio(CPU) ↔ 중계기 ↔ 클라우드 설정의 스튜디오로 첫 계정 만들기·목소리 준비·43초 음성 영상 제작까지 확인.
- 실제 배포(2026-11-05): Actions #4 성공, 공개 주소 응답(잠에서 깨는 데 약 12초), 휴대폰 폭에서 첫 계정 화면 확인. 첫 계정·GPU 목소리 준비·영상 1편 비용은 아직 확인 전.
- 다시 배포할 때 DB: 새 서버는 이전 서버의 임대 표시(`/data/studio.db.lease`)가 풀릴 때까지 최대 2분 기다렸다 이어받는다.
