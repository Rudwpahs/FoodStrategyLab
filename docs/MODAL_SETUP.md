# Modal 클라우드에 스튜디오 올리기 (컴퓨터 없이 휴대폰으로)

서버를 직접 만들거나 명령창을 쓸 필요가 없습니다. **가입 → 열쇠 3개 넣기 → 버튼 한 번**이면 됩니다(휴대폰 브라우저로도 가능).

- 비용: Modal 무료 플랜(Starter)은 **매달 $30 무료 크레딧**을 줍니다. 아래 4단계에서 **지출 한도를 $0**으로 정하면, 크레딧을 다 써도 돈이 청구되지 않고 작업이 멈춥니다.
- 영상 1편 예상 비용: 목소리(GPU L4) 약 $0.05~0.1 + 렌더(CPU) 약 $0.1~0.3 → **한 달 수십 편까지 무료 크레딧 안**(직접 재 본 값이 아닌 추정, 실제 값은 Modal 사용량 화면에서 확인)
- 주소: `https://...modal.run` 인터넷 주소로 열립니다. 로그인(비밀번호 10자 이상, 10번 틀리면 15분 잠김)으로 보호됩니다.
- 확인한 근거 (2026-11-04): [Modal 가격](https://modal.com/pricing), [결제 안내](https://modal.com/docs/guide/billing), [지출 한도](https://modal.com/docs/guide/budgets)

## 1. Modal 가입

1. https://modal.com → **Sign up** → **GitHub로 가입**(가장 간단)
2. 결제 수단(카드)을 등록합니다. Modal은 무료 플랜도 카드 등록이 필수입니다(본인 확인용). 다음 단계에서 지출 한도를 $0으로 막습니다.

## 2. 지출 한도 $0 (꼭 하세요)

Modal → **Settings → Usage & Billing** → **Spend limit**을 `0`으로 저장.
→ 무료 크레딧을 넘는 작업은 Modal이 멈춥니다. 청구되지 않습니다.

## 3. 열쇠 3개를 GitHub에 넣기

1. Modal → **Settings → API Tokens → New Token** → 화면에 나온 두 값을 복사
   - `Token ID` (ak-로 시작)
   - `Token Secret` (as-로 시작)
2. GitHub 저장소 `Rudwpahs/FoodStrategyLab` → **Settings → Secrets and variables → Actions → New repository secret**에서 하나씩 추가:

| 이름 | 값 |
| --- | --- |
| `MODAL_TOKEN_ID` | Token ID |
| `MODAL_TOKEN_SECRET` | Token Secret |
| `STUDIO_SETUP_CODE` | 직접 정하는 **설정 코드**. 남이 짐작하기 어렵게 12자 이상(문장·숫자 섞기)으로 정하세요. 처음 계정을 만들 때 한 번만 씁니다 |

이 값들은 채팅·메모에 붙여넣지 말고 위 화면에만 넣으세요.

## 4. 배포 버튼 누르기

GitHub 저장소 → **Actions → Deploy to Modal → Run workflow** → 브랜치 `main` → **Run workflow**

(이 버튼은 Modal 배포 기능이 `main`에 합쳐진 뒤에 보입니다. 비밀값을 넣은 뒤 `main`에 새 내용이 들어가도 자동으로 배포됩니다.)

- 처음에는 **20~40분** 걸립니다(서버 이미지 만들기). 다음부터는 몇 분.
- 끝나면 실행 화면 맨 아래 **Summary**에 **스튜디오 주소**가 나옵니다. 적어 두세요.
- 그 뒤로는 `main`에 새 기능이 들어갈 때마다 자동으로 다시 배포됩니다.

## 5. 휴대폰에서 첫 계정 만들기

1. 스튜디오 주소를 휴대폰 크롬으로 엽니다.
2. **설정 코드**(3단계에서 정한 값), 이름, 아이디, 비밀번호(10자 이상)를 넣고 **계정 만들고 시작하기**.
3. 다음부터는 아이디·비밀번호로 로그인합니다. 가족 계정이 필요하면 알려 주세요(화면에서 추가하는 기능은 아직 없음).

앱처럼 쓰기: 크롬 메뉴 → **홈 화면에 추가**, 또는 맛 연구소 앱(APK)을 설치하고 첫 화면에 스튜디오 주소를 넣습니다. Tailscale은 필요 없습니다.

## 6. 처음 한 번: 맛조수 목소리 준비

배포 뒤 서버가 처음 켜지면 **자동으로** GPU에서 목소리 엔진을 내려받고 '맛조수' 목소리를 만듭니다(10~30분 예상). 그동안에도 스튜디오는 쓸 수 있고, 영상 만들기만 목소리 준비 뒤에 하세요.

**다른 목소리·말 빠르기**: [캐릭터·목소리] 화면에서 맛조수 기본 목소리 말고 다른 목소리(톤을 낮춘 맛조수, 차분한 여성, 남성 등)와 말 빠르기(느리게~빠르게)를 고를 수 있습니다. '모든 목소리로 만들기'를 누르면 같은 문장을 목소리마다 들어 볼 수 있어요. 목소리마다 저장소에 기준 녹음(`tools/setup/voices.json`, `tools/setup/voices/`)이 있어 어디서 만들어도 같은 목소리가 납니다.

## 7. 레시피 사진·파일로 만들기 켜기 (Claude API)

[새 콘텐츠]에서 레시피 사진·PDF를 올리면 Claude가 글자를 읽어 레시피로 옮기고, 후보 영상 5개를 바로 보여 줍니다.

1. https://console.anthropic.com → 가입 → **Billing**에서 소액 충전(예: $5) → **API Keys → Create Key**
2. GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret
   | 이름 | 값 |
   | --- | --- |
   | `ANTHROPIC_API_KEY` | 만든 열쇠 (sk-ant-…) |
   | `CLAUDE_MONTHLY_BUDGET_USD` | (선택) 한 달 한도, 기본 `100` |
3. Actions → **Deploy to Modal → Run workflow**

- 모델: **Claude Opus 5.5** (손글씨를 가장 잘 읽는 모델, 1백만 토큰당 입력 $4 · 출력 $20). 생각 정도는 `high`(손글씨 대조에 유리). 레시피 사진 한 장 **약 $0.1~0.2(약 140~280원, 추정)**. 기본 한도 $100이면 한 달 수백 장. 한도에 닿으면 그달은 "직접 입력"만 됩니다. 생각 정도는 Modal 비밀값 `CLAUDE_EFFORT`(low·medium·high·xhigh·max)로 바꿀 수 있습니다. 더 아끼려면 Modal 비밀값 `CLAUDE_MODEL=claude-haiku-5-5`(한 장 약 3원).
- 재료·분량·순서는 적힌 그대로 옮기고, 흐린 글자는 추측하지 않고 "확인할 곳"으로 알려 줍니다. 자료에 없던 주제·핵심 원리·흔한 실수는 **"AI 제안 · 확인 필요"**로 표시됩니다. 주제 후보는 3개가 나오고, 각각 레시피의 몇 번 순서·팁에서 나왔는지 인용이 붙습니다. 인용이 원문에 없거나 레시피에 없는 숫자·건강 주장이 들어 있으면 서버가 뒤로 미루고 "확인 필요"로 알려 줍니다. 승인 전에 꼭 확인하세요.
- **AI 티 다듬기 (im-not-ai)**: [검수]·[대본] 화면의 대사와 [게시] 화면의 블로그 원고에 버튼이 있습니다. 규칙 검사(무료)로 AI 티를 찾은 뒤, Claude가 im-not-ai 룰북(85개 패턴)대로 다듬고, 서버가 숫자·분량·인용·말투·변경률을 다시 검사해 걸린 문장은 원래대로 둡니다. 전후를 보고 [적용]을 눌러야 반영됩니다(대사는 새 대본 버전 → 재검수). 연구자 답변과 재료·순서·팁 목록은 보내지 않습니다. 1회 약 $0.1, 레시피 읽기와 같은 월 한도를 씁니다. 규칙 검사에서 AI 티가 없으면 Claude를 부르지 않습니다.
- **인스타그램 올리기** (사례 조사: `docs/research/content-strategy/instagram-cases.md`): 설명 글에 재료·만드는 법을 원본 그대로 싣고 해시태그는 5개까지. 표지(3:4 격자 안에 제목)를 함께 보내고 AI 정보 라벨을 요청합니다(받지 않는 계정이면 앱에서 켜라고 알려 줌, 끄기: Modal 비밀값 `IG_AI_LABEL=0`). [체험용 릴스로 올리기]를 켜면 팔로워가 아닌 사람에게 먼저 보여 줍니다. [레시피 카드 N장 올리기]는 넘겨 보는 카드 게시물을 따로 올립니다. 올리기 전 점검 목록이 화면에 나옵니다.
- 올린 원본 사진·파일은 콘텐츠와 함께 보관되어 언제든 대조할 수 있습니다.
- 영상은 후보 5개 모두 목소리를 넣어 미리보기로 보여 주고(브라우저가 그림, 렌더 비용 0원), **고른 1개만** 서버에서 완성 영상(MP4)으로 만듭니다.

## 알아 둘 점

- **잠들기**: 20분 동안 아무도 쓰지 않으면 서버가 잠들어 돈이 들지 않습니다. 다음에 주소를 열면 **10~30초** 뒤 깨어납니다.
- **영상 만들기 중 앱 닫기**: 괜찮습니다. 제작 중에는 서버가 스스로 깨어 있습니다.
- **목소리 GPU**: 목소리를 만들 때만 켜지고, 마지막 요청 4분 뒤 꺼집니다. 처음 켜질 때 1~3분 더 걸릴 수 있습니다.
- **데이터**: 레시피·영상·승인 기록은 Modal 저장소(Volume `matlab-data`)에 남습니다. 서버가 잠들거나 다시 배포해도 지워지지 않습니다. 중요한 영상·원고는 휴대폰에도 내려받아 두세요.
- **드물게 중단**: Modal은 아주 드물게 서버를 옮기며 작업을 끊을 수 있습니다(선점). 그러면 진행 중이던 영상은 "실패"로 표시되니 다시 누르면 됩니다.
- **사용량 확인**: Modal → Usage & Billing에서 이번 달 쓴 금액을 볼 수 있습니다.

| "지출 한도" 때문에 멈춤 | 이번 달 무료 크레딧을 다 쓴 것. 다음 달에 다시 되거나, 한도를 올리면 유료로 계속 |

## 개발자용 메모

- 구성: `deploy/modal/app.py` (web 함수: Node 스튜디오 전체, CPU 0.125~8코어·메모리 1~16GB 탄력, 요청 없으면 20분 뒤 잠듦 / Voice 클래스: VoiceStudio+VoxCPM2 on L4 GPU, 4분 뒤 꺼짐)
- 목소리 중계: `deploy/modal/voice_proxy.py` — 웹 컨테이너 안 `127.0.0.1:3901`이 VoiceStudio처럼 보이고, 요청을 GPU 함수 호출로 넘긴다. `/health`·엔진/목소리 목록은 GPU를 깨우지 않게 바로 답하거나 기억해 둔 값을 쓴다.
- DB: 컨테이너 디스크(`/root/matlab-db/studio.db`)에서 쓰고 5초마다 `/data/studio.db`로 복사(`apps/studio/server/dbSnapshot.ts`). 새 컨테이너는 복사본에서 시작.
- 제작 중 깨워 두기: `KEEPALIVE=1`이면 제작하는 동안 1분마다 공개 주소의 `/api/health`를 부른다.
- 첫 계정: `STUDIO_SETUP_CODE`가 있고 계정이 없으면 화면에서 만들기(`POST /api/auth/setup`), 틀리면 로그인 실패처럼 횟수 제한.
- 로컬 검증(2026-11-04): 실제 VoiceStudio(CPU) ↔ 중계기 ↔ 클라우드 설정의 스튜디오로 첫 계정 만들기·목소리 준비·43초 음성 영상 제작까지 확인.
- 실제 배포(2026-11-05): Actions #4 성공. `https://rudwpahs--matlab-studio-web.modal.run` 응답(잠에서 깨는 데 약 12초), 공개 주소 인식, 휴대폰 폭에서 첫 계정 화면 확인. 첫 계정·GPU 목소리 준비·영상 1편은 아직 확인 전.
- 다시 배포할 때 DB: 새 서버는 이전 서버의 임대 표시(`/data/studio.db.lease`)가 풀릴 때까지 최대 2분 기다렸다 이어받는다.
