### C. 아직 수동 복사·붙여넣기나 외부 앱에 의존하는 기능

1. **AI 대본**: 프롬프트를 복사해 무료 AI 채팅에 넣고 답을 다시 붙여넣는다.
2. **생성 AI 장면**: ChatGPT·Gemini 앱에서 직접 만들어 내려받은 뒤 업로드한다.
3. **인스타그램·유튜브 게시**: 문구 복사 + ZIP 내려받기 후 앱에서 직접 올린다.
4. **네이버 블로그 게시**: 본문 복사 → 편집기 붙여넣기 → 사진 직접 첨부.
5. **게시 결과 기록**: 게시 URL을 저장하는 곳이 없다.

## 3. 기준 사례 실측: 호두정과 음성 포함 영상

방법: 영상 오디오를 Whisper(small)로 단어 단위 받아쓰기 → 스튜디오가 만든 장면·자막 타임라인과 비교.

| 항목 | 결과 |
| --- | --- |
| MP4 | H.264 + AAC, 37.0초, 평균 -19.2 dB / 최대 -1.4 dB |
| 장면 2~8: 들린 말과 대사 일치율 | 0.77~1.00 (받아쓰기 자체 오차 포함) |
| 자막이 떠 있는 동안 들린 단어가 그 자막에 있는 비율 | 45/54 = 83% |
| 장면 2~8: 말 시작과 자막 시작 차이 | -0.31 ~ +0.36초 |
| **장면 1** | **무음** → 위 결함 |

**수정 후 재측정 (2026-11-03, 같은 방법)**: 영상 38.3초, 8개 장면 모두 음성 있음.

| 항목 | 수정 전 | 수정 후 |
| --- | --- | --- |
| 장면 1 일치율 | 무음 | 0.97 |
| 장면별 일치율 | 0.77~1.00 (장면 2~8) | 0.83~1.00 (전 장면) |
| 자막 일치율 | 45/54 = 83% | 51/59 = 86% |
| 말 시작 vs 자막 시작 | -0.31~+0.36초 | -0.47~+0.02초 (자막이 말보다 최대 0.47초 늦게 뜸) |

뒤쪽 장면에서 자막이 말보다 조금 늦게 뜬다. 단어 시간이 글자 수 추정이라 생기는 차이로 보이며, 받아쓰기 모델을 설치하면 줄일 수 있다(B 분류).

## 5. 보존할 원칙 (변경 금지)

- 패키지 경계: `recipe-core`(규칙·순수 함수) / `video`(렌더) / `publishing`(출력물) / `apps/studio`(서버·화면)
- 원본 레시피는 AI가 바꾸지 않는다. 재료·순서 카드는 원본에서만 만든다.
- 승인은 대본 **버전**에 묶인다. 대본·원본이 바뀌면 승인이 풀린다.
- 승인되지 않은 대본은 최종 출력·게시할 수 없다. "검토한" 표현은 승인 후에만 쓴다.
- 비상업 라이선스 모델은 채널용으로 쓰지 않는다.
