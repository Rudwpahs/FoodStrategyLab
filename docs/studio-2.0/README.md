## 쉬운 설명 (비전문가용)

### 1. 지금 웹페이지에서 실제로 가능한 일

- 레시피(재료·분량·순서)를 입력하면 **원본 그대로** 저장되고, 영상 대본 초안이 무료로 바로 만들어진다.
- 대본을 고치고, 원본과 다른 분량·빠진 재료가 있는지 **자동 검사**를 받고, 이희재 연구자가 체크리스트를 확인해 **승인**한다. 승인 후 대본을 고치면 승인이 자동으로 풀린다.
- 승인된 대본으로 **세로 영상(MP4)**을 만든다: 3D 주방에서 맛조수가 요리하고, 맛조수 목소리(VoiceStudio)와 숏폼 자막이 들어간다. 음식 사진이나 AI로 만든 영상 조각도 끼워 넣을 수 있다.
- 네이버 블로그 원고, 인스타그램·유튜브 설명문, 자막 파일, 썸네일, 레시피 카드를 만들어 **한 번에 내려받는다**.
- 단, 지금은 **스튜디오를 켠 그 컴퓨터에서만** 열린다. 로그인도 아직 없다.

### 2. 다음에 구현할 기능 (순서대로)

1. 영상 만들기 **진행 표시·취소·다시 시도**, 쉬운 오류 안내. 원본과 다른 분량이 있는 대본은 **승인 자체를 막기**.
2. 웹에서 버튼 하나로 **AI 대본 만들기**, 장면 하나만 다시 쓰기, 한 달 사용 금액 한도.
3. 블로그 미리보기에서 바로 고치기, 사진 하나씩 내려받기, 네이버 글쓰기 창 열기, 올린 글 주소 기록. 영상·블로그·인스타 설명의 **재료·분량이 서로 같은지 자동 검사**.
4. **로그인**을 붙이고, 다른 컴퓨터·휴대폰 브라우저에서도 들어올 수 있게 연결.
5. 최종 확인 버튼을 누르면 **인스타그램 릴스로 바로 게시**하고 게시물 주소 기록(같은 영상 두 번 올리기 방지).
6. 자동 백업, PC 켜면 자동 실행.

### 3. 사용자가 직접 준비하거나 승인해야 하는 사항

### 4. 실제 운영까지 남은 장애 요소

- **네이버 블로그 자동 게시는 공식적으로 불가능**하다(공식 글쓰기 API 종료). 끝까지 "복사 → 붙여넣기 → 사진 첨부"는 사람이 한다. 대신 그 과정을 최대한 짧게 만든다.
- **인스타그램 공식 게시**는 Meta 앱 설정·계정 전환·권한 확인이 끝나야 실제로 쓸 수 있다. 세부 조건 일부(권한 이름, 테스터만으로 가능한지, 업로드 방식)는 Meta 공식 문서로 다시 확인해야 한다.
- **속도**: 그래픽카드 없는 컴퓨터에서는 40초 영상 하나에 20~30분, 목소리 생성도 수 분이 걸린다. 그래픽카드가 있는 PC에서 다시 재 봐야 한다.
- **PC 의존**: 처음에는 집 PC가 켜져 있어야 만들 수 있다. 완전히 클라우드로 옮기면 월 수만 원 이상 든다.
- **실환경 미확인**: Windows용 VoiceStudio 앱 연결, PC에서 영상 제작 끝까지 해 보기, 네이버 붙여넣기 결과.
- **AI 품질**: AI가 쓴 대본도 결국 이희재 연구자가 확인해야 한다. 원본 위반은 자동으로 막지만, 맛 표현·팁의 정확성은 사람이 본다.
- **저작권·라이선스**: 비상업 전용 음성 모델(OmniVoice)은 쓰지 않는다. 생성 AI 영상·음악의 상업 이용 조건은 서비스별로 확인이 필요하다.
