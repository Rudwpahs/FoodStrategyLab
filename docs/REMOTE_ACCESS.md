# 휴대폰·다른 PC에서 스튜디오 쓰기

> **컴퓨터 없이 휴대폰만으로 쓰려면** [오라클 무료 서버 설정](ORACLE_SETUP.md)을 따르세요. 아래는 집 컴퓨터를 서버로 쓰는 방법입니다.

영상과 맛조수 목소리는 **스튜디오 PC**(어머니 PC)에서 만들어집니다. 휴대폰 앱과 다른 PC는 그 PC에 접속해 화면을 보는 방식입니다. 그래서 쓰는 동안에는 스튜디오 PC가 켜져 있어야 합니다.

## 1. 스튜디오 PC 준비 (처음 한 번)

PowerShell에서 하나씩:

```
cd C:\dev\FoodStrategyLab
git pull origin main
npm install
```

계정 만들기 (비밀번호는 10자 이상, 화면에 보이지 않아요):

```
npm run user:add -- heejae 이희재
```

필요하면 가족 계정도 같은 방법으로 만듭니다. 승인 기록에는 **로그인한 사람 이름**이 남습니다.
비밀번호를 바꾸려면 `npm run user:add -- heejae --reset`.

## 2. 접속 방법 고르기

### 방법 A — Tailscale (추천: 인터넷에 공개하지 않음, 무료)
나만 쓰는 사설 연결입니다. 스튜디오 주소가 인터넷에 노출되지 않습니다.

1. 스튜디오 PC와 휴대폰에 Tailscale 앱 설치, 같은 계정으로 로그인
2. 스튜디오 PC에서 실행 (Windows 방화벽이 물으면 "개인 네트워크" 허용):
   ```
   $env:HOST="0.0.0.0"; npm run start
   ```
3. 휴대폰 앱의 주소: `http://<PC 이름>:5178` (Tailscale 앱에 보이는 PC 이름)

### 방법 B — Cloudflare Tunnel (인터넷 주소, 외부 공개)
어디서나 `https://` 주소로 들어올 수 있지만 **인터넷에 공개**됩니다. 로그인이 있어야 하고(계정이 없으면 스튜디오가 외부 요청을 모두 거절), 공개 전에 한 번 더 확인합니다.
도메인과 Cloudflare 계정이 필요합니다. 설정은 Cloudflare Zero Trust → Tunnels에서 `http://localhost:5178`을 연결합니다. 이 경우 `HOST`는 바꾸지 않습니다.

## 3. 휴대폰 앱

- **안드로이드 앱(APK)**: `matlab-studio.apk`를 휴대폰에 받아 설치합니다. 처음 설치할 때 "출처를 알 수 없는 앱 설치 허용"을 한 번 켜야 합니다(테스트 서명 앱이라서).
  처음 열면 스튜디오 주소를 입력합니다. 메뉴(⋮)에서 주소를 바꾸거나 새로고침할 수 있습니다.
- **앱 설치 없이**: 휴대폰 크롬에서 스튜디오 주소를 열고 메뉴 → "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있습니다. (https 주소일 때 가장 잘 됩니다)

앱은 사진·클립 올리기와 ZIP·이미지 내려받기(휴대폰 '다운로드' 폴더)를 지원합니다. 인스타그램·네이버 링크는 휴대폰 브라우저로 열립니다.

## 4. 안전 규칙 (자동 적용)

- 계정이 하나도 없으면 스튜디오 PC에서 직접 연 화면만 동작합니다 (터널·다른 기기는 거절).
- 계정을 만들기 전에는 `HOST`를 열 수 없습니다 (스튜디오가 시작을 거부).
- 비밀번호는 암호화(해시)해 저장하고, 10번 틀리면 15분 잠깁니다.
- 다른 사이트에서 보낸 변경 요청은 거절합니다.

## 5. 앱 다시 만들기 (개발자용)

```
cd apps/android
gradle assembleDebug
```

Android SDK 경로는 `apps/android/local.properties`의 `sdk.dir`에 적습니다. 결과: `app/build/outputs/apk/debug/app-debug.apk`.
정식 배포(플레이스토어)에는 별도 서명 키가 필요합니다.
